# Site vitrine — CEC Sailly-sur-la-Lys

Première maquette responsive du nouveau site vitrine.

## Prévisualisation

Ouvrir \`site-vitrine/index.html\` avec un serveur statique. Le site ne modifie pas l’application React existante : tous les fichiers de la vitrine sont isolés dans ce dossier et sur la branche \`site-vitrine-v1\`.

## Contenu de cette version

- accueil et proposition de valeur ;
- horaires d’éducation du chiot et du chien adulte ;
- checklist pour une première séance ;
- disciplines : Obéissance, Ring et IGP ;
- calendrier 2026 avec statut automatique des événements ;
- présentation du club, partenaires et contacts ;
- navigation mobile, accessibilité de base et métadonnées SEO.

Les deux photos sont temporairement chargées depuis le CDN du site Wix. Avant la migration définitive, les fichiers originaux devront être copiés dans le projet.
